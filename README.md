📊 SaaS Subscription Analytics Dashboard
📌 Project Overview

This project presents an interactive Business Intelligence dashboard developed in Power BI to analyze SaaS subscription performance, customer churn behavior, revenue trends, and customer segmentation dynamics.

The dashboard enables data-driven decision-making through KPI monitoring, behavioral analysis, and advanced interactive reporting techniques.

🎯 Business Objectives

• Monitor subscription performance metrics
• Identify churn risk patterns
• Analyze revenue distribution & growth trends
• Understand customer segmentation behavior
• Support retention & customer value strategies

📈 Key KPIs

✅ Total Customers
✅ Active Customers
✅ Churn Rate
✅ Monthly Recurring Revenue (MRR)
✅ Average Revenue Per User (ARPU)
✅ Customer Lifetime Value (CLV)
✅ Average Customer Lifespan

📊 Dashboard Pages

✔ Executive Overview
✔ Churn & Retention Insights
✔ Revenue & Growth Insights
✔ Customer Segmentation
✔ Retention & Customer Value Strategy

🚀 Advanced Dashboard Features ⭐⭐⭐⭐⭐

✅ Drillthrough Analysis
Allows deep-dive exploration of customer-level data directly from summary visuals.

✅ Dynamic Tooltips
Provides contextual insights and additional metrics upon hovering over visuals.

✅ Interactive Page Navigation
Sidebar-based navigation enabling seamless user experience across report pages.

✅ Dynamic Page Titles
Titles update based on user interactions and filtering context.

✅ Cross-Filtering & Interactivity
Visuals dynamically respond to slicers and selections.

🛠 Tools & Technologies

• Power BI Desktop
• DAX (Data Analysis Expressions)
• Data Modeling
• Interactive Dashboard Design
• Business Intelligence Reporting

📂 Dataset

The dataset simulates SaaS subscription customer behavior including:

• Subscription Plans
• Contract Types
• Tenure Metrics
• Churn Status
• Revenue Attributes
• Engagement Indicators
• Payment Methods

🔍 Key Business Insights

• Customers on monthly contracts exhibit higher churn probability
• Revenue concentration observed among long-tenure customers
• Subscription plan distribution influences retention trends
• Customer lifetime value strongly correlates with tenure & engagement
• Retention strategies should target high-value churn-risk segments
